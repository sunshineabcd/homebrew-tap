# PureCanvas Homebrew Tap

```bash
brew tap sunshineabcd/tap
brew install purecanvas
```

- `purecanvas` — PureCanvas 独立 CLI（采集 / 套壳 / 多语言成图 / 商店规格校验 / App Preview 视频）
- 发布包：签名 + Apple 公证，Apple Silicon（arm64），macOS 14+
- 流程驱动采集需要完整 Xcode；首次使用建议 `purecanvas capture doctor`

发布源：[sunshineabcd/purecanvas-cli](https://github.com/sunshineabcd/purecanvas-cli)
